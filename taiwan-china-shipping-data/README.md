# 2026 兩岸運價指數 — 開放數據集

> 速豹集運發布 2026 年台灣寄中國大陸各渠道運費、時效、可寄品類對比數據。

## 數據來源
- 速豹集運 2026 H1 實際運營記錄（2,000+ 客戶訂單）
- 12 次同重量跨渠道比價測試
- 每個重量段取自 3 次以上報價中位數

## 數據集

| 文件 | 內容 |
|------|------|
| `data/price-comparison-2026.csv` | 1-50kg 重量段 × 4 渠道運費 |
| `data/transit-time-2026.csv` | 各渠道空運/海運時效實測 |
| `data/prohibited-items-2026.csv` | 可寄/禁運/限制品類清單 |
